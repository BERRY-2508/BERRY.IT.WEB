BERRY IT NETWORK UTILITY

Understand your connection. Berry IT Network Utility brings real network diagnostics into one native, branded Windows desktop interface — without opening a browser-based dashboard.

Release status: Windows preview build under testing. The PowerShell source is published on GitHub. The optional network.berry.it.com subdomain is not yet configured.

Network dashboard

Device hostname, local and public IP addresses, Windows details, active adapter, gateway and DNS information.

Internet speed test

Run download and upload measurements directly from the home dashboard or the dedicated Speed Test view. See latency, jitter and history.

Technician diagnostics

Continuous ping graph, DNS records, traceroute, TCP port tests, adapter details and exportable reports.

Built for Windows PowerShell

Berry IT Network Utility uses a native WPF interface with your approved BERRY IT imagery, charcoal panels, red accents and Orbitron headings. Most read-only diagnostics do not need administrator privileges.

Launch the GitHub-hosted script from Windows PowerShell after reviewing its source:

irm https://raw.githubusercontent.com/BERRY-2508/BERRY.IT.WEB/main/network-utility/NetworkUtility.ps1 | iex

Preview: This build still needs Windows testing. Review the PowerShell source before running. The shorter subdomain launch command is not yet configured.
